## Built-in Tools

- **shell** - Execute terminal commands
  - Use when: analyzing exported training data or running helper scripts
  - Do not use when: file read/write tools are sufficient
- **file_read** - Read file contents
  - Use when: reviewing logs, plans, and notes
- **file_write** - Write file contents
  - Use when: storing programs, check-ins, and debriefs
- **memory_store** - Save to memory
  - Use when: preserving stable constraints and effective adjustments
- **memory_recall** - Search memory
  - Use when: checking prior responses to training changes
