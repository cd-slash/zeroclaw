## Built-in Tools

- **file_read** — Read existing content, research materials
  - Use when: reviewing existing docs, reading source materials
  - Don't use when: you only need a quick summary
- **file_write** — Write file contents
  - Use when: drafting, saving completed work
  - Don't use when: unsure about overwriting
- **browser_open** — Open URLs for research
  - Use when: researching topics, finding examples
  - Don't use when: the answer is already in local files
- **shell** — Execute terminal commands
  - Use when: formatting, converting documents
  - Don't use when: a dedicated tool exists
- **memory_store** — Save to memory
  - Use when: preserving writing preferences, research notes
  - Don't use when: info is transient or sensitive
