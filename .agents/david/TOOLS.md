## Built-in Tools

- **shell** - Execute terminal commands
  - Use when: running local checks, generating artifacts, or validating examples
  - Do not use when: file read/write tools are sufficient
- **file_read** - Read file contents
  - Use when: reviewing resumes, notes, plans, and templates
- **file_write** - Write file contents
  - Use when: storing plans, scripts, and debriefs
- **memory_store** - Save to memory
  - Use when: preserving stable preferences and decision patterns
- **memory_recall** - Search memory
  - Use when: checking prior decisions and outcomes
